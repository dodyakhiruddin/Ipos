Petunjuk dan Penggunaan Sistem iPos 5 [DONET CELL]

Tombol Pintas (Shortcut Keyboard)
  • F2 : Buka langsung layar 4. Penjualan (Kasir POS).
  • F3 : Buka pencarian barang di Kasir atau 2. Master Data.
  • F4 : Buka pemindai kamera/gambar Auto-Scan OCR Nota & Struk.
  • F10 : Simpan transaksi kasir & cetak struk thermal 80mm.
Alur Operasional Harian Konter
  1. Cek Sumber Dana (Menu 8): Pastikan saldo Kas Laci, Rekening BRILink, dan Server Pulsa sesuai kondisi riil.
  2. Master Data & Pembelian (Menu 2 & 3): Input stok voucher/aksesoris baru atau gunakan Import Excel & Scan Nota.
  3. Transaksi Harian (Menu 4, 5, 6): Layani penjualan retail di kasir, transfer/tarik tunai BRILink, pulsa PPOB, serta tiket Service HP.
  4. Akuntansi & Laporan (Menu 9 & 10): Pantau laba bersih harian serta export laporan ke Excel/CSV.

Arsitektur Offline-First + Supabase Cloud: Semua transaksi & data user otomatis tersimpan di IndexedDB Browser (cepat & jalan tanpa internet). Jika URL & Anon Key Supabase diisi, data akan otomatis disinkronkan ke PostgreSQL Cloud saat online. 
-- Jalankan di SQL Editor Supabase Anda:
-- 1. Tabel Utama Penyimpanan State Lengkap (termasuk Sumber Dana Dinamis, User, Stok & Transaksi)
CREATE TABLE IF NOT EXISTS donet_cell_state (
  id TEXT PRIMARY KEY,
  payload JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. (Opsional) Tabel Relasional Sumber Dana / Dompet untuk Query Laporan Eksternal
CREATE TABLE IF NOT EXISTS donet_cell_wallets (
  tenant_db TEXT NOT NULL,
  wallet_id TEXT NOT NULL,
  wallet_name TEXT NOT NULL,
  wallet_type TEXT DEFAULT 'BANK',
  balance NUMERIC(15, 2) DEFAULT 0,
  description TEXT,
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  PRIMARY KEY (tenant_db, wallet_id)
);

-- 3. (Opsional) Tabel Relasional Service HP (Tanda Terima & Biaya Internal)
CREATE TABLE IF NOT EXISTS donet_cell_service_tickets (
  tenant_db TEXT NOT NULL,
  trx_no TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  customer_name TEXT NOT NULL,
  customer_phone TEXT,
  device_model TEXT NOT NULL,
  issue_description TEXT NOT NULL,
  sparepart_code TEXT,
  sparepart_qty INTEGER DEFAULT 0,
  modal_sparepart NUMERIC(15, 2) DEFAULT 0,
  service_fee NUMERIC(15, 2) DEFAULT 0,
  dest_wallet_id TEXT,
  status TEXT DEFAULT 'PROSES',
  completed_at TIMESTAMPTZ,
  PRIMARY KEY (tenant_db, trx_no)
);

-- Aktifkan RLS & Kebijakan Akses
ALTER TABLE donet_cell_state ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon all state" ON donet_cell_state FOR ALL USING (true) WITH CHECK (true);

ALTER TABLE donet_cell_wallets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon all wallets" ON donet_cell_wallets FOR ALL USING (true) WITH CHECK (true);

ALTER TABLE donet_cell_service_tickets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon all service" ON donet_cell_service_tickets FOR ALL USING (true) WITH CHECK (true);
